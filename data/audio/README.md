# Audio and Trace Artifacts

The complete audio and trace artifacts for **Real-Time Audio Tool Bench** are
available through the following anonymous Figshare link:

**[Download the complete artifact](https://figshare.com/s/5635155a03e3faae60d3)**

The artifact contains:

- Clean TTS audio for the 1,040 benchmark tasks.
- Voice-cloned audio for the same tasks.
- The task traces shared by the TTS and voice-cloning conditions.
- A README and SHA-256 checksums for integrity verification.

Audio is stored as PCM16, 24 kHz, mono unless otherwise noted by the benchmark
metadata.
